# 当前技能库验证

本轮验证内容为技能文档与本地 Git 接入，不是固件、硬件或一般 agent 成功率验证。

## 结构与保留项

使用继承的 Python 标准库测试，扩展到 9 项技能。首次检查在旧根索引上检出新增技能没有入口；更新索引和引用后复测。工程技能与试用技能分开；原 3 项试用技能正文、参考、experimental/not-run 元数据及旧评估案例不改。旧情景验证记录保持历史日期。

独立目录引用需在整项技能复制后仍然可读；技能不得依赖另一个产品的绝对路径、工具私有文件或设备标识。新文档仅包含可移植方法。许可和来源单独保留。

## 有限 agent 情景应用

新一轮离线输入覆盖：采样与显示错位、混合状态帧率、真实数组回放、不确定更新，以及素材／测试／有效配置。基线已经正确处理多数风险，不能声称新技能证明了普遍改进。技能组运行只读取相关技能及其按需参考；不操作项目或设备。

原始输入、回答和人工逐项评阅放在 `evals/realtime-rendering/`。一次基线与一次有技能应用，只是有限定性检查，不是统计比较、客户端自动触发测试或完整产品实战。原 3 项试用技能的 11 个评估案例仍未执行。

## 本地接入检查

实际结果在完成本地 submodule 接入后补齐。检查应包括 Git mode160000、固定 commit、完整工程技能链接、内部引用、清洁子模块、Echoy 产品文件未改和本地递归克隆可复现。不能仅凭 `.gitmodules` 已生成就写接入通过。

远程建仓、远程递归 clone、客户端本次会话动态发现、固件构建、模拟器运行、设备操作和物理验收均不在本轮执行范围。
